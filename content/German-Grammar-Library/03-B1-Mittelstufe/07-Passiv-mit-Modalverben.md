# 🇩🇪 Passiv mit Modalverben

> **Niveau:** B1
>
> **Lernziel:** Ich kann Passivsätze mit Modalverben im Präsens und Präteritum bilden und damit Möglichkeiten, Pflichten und Erlaubnisse ausdrücken.

## ⚡ Die Idee in 10 Sekunden

Im Passiv mit Modalverb steht das **Modalverb** auf Position 2, das **Partizip II** und **werden** stehen am **Ende**: *Das Haus **muss** gebaut **werden**.* Im Präteritum: *Das Haus **musste** gebaut **werden**.* So drückt man aus, was **getan werden muss, kann, darf oder soll** – ohne den Täter zu nennen.

## 🧩 Goldene Formel

```text
Subjekt + Modalverb + ... + Partizip II + werden
Das Haus + muss     + ... + gebaut      + werden
```

## 📊 Mini-Regelkarte

| Frage | Antwort |
|---|---|
| Was bedeutet es? | Passiv + Modalverb |
| Wann benutzt man es? | Bei Pflicht, Möglichkeit, Erlaubnis |
| Wie bildet man es? | Modalverb + Partizip II + werden |
| Was muss man beachten? | *werden* steht am Satzende |

## 👀 Visuelle Merkhilfe

| Modalverb | Beispiel |
|---|---|
| müssen | Das Haus **muss** gebaut **werden**. |
| können | Das Problem **kann** gelöst **werden**. |
| dürfen | Hier **darf** nicht geraucht **werden**. |
| sollen | Die Regel **soll** erklärt **werden**. |
| wollen | Das Auto **will** repariert **werden**. |

## 📋 Die wichtigsten Regeln

**1. Präsens**

*Die Aufgabe **muss** bis morgen **gemacht werden**.*

**2. Präteritum**

*Die Aufgabe **musste** bis gestern **gemacht werden**.*

**3. Reihenfolge am Ende**

**Partizip II + werden** – immer in dieser Reihenfolge.

**4. Bedeutung der Modalverben im Passiv**

| Modalverb | Bedeutung | Beispiel |
|---|---|---|
| müssen | Notwendigkeit | Das muss gemacht werden. |
| können | Möglichkeit | Das kann gemacht werden. |
| dürfen | Erlaubnis/Verbot | Das darf nicht gemacht werden. |
| sollen | Auftrag/Empfehlung | Das soll gemacht werden. |

**5. Negation**

*Das **darf nicht** gemacht **werden**.*

**6. Agens bleibt meist weg**

*Das Formular **muss** ausgefüllt **werden**.* (von wem? egal)

**7. Mit *von* möglich**

*Das Formular **muss von** jedem Studenten **ausgefüllt werden**.*

**8. Nebensatz**

*…, weil das Haus **gebaut werden muss**.*

**9. Häufige Formeln**

*Das muss man machen.* → *Das muss gemacht werden.*

## Beispiele

🇩🇪 Das Haus **muss** gebaut **werden**.
🇮🇷 خانه باید ساخته شود.

🇩🇪 Das Problem **kann** gelöst **werden**.
🇮🇷 مشکل می‌تواند حل شود.

🇩🇪 Hier **darf** nicht geraucht **werden**.
🇮🇷 اینجا نباید سیگار کشیده شود.

🇩🇪 Die Regel **soll** erklärt **werden**.
🇮🇷 قاعده باید توضیح داده شود.

🇩🇪 Das Formular **muss** ausgefüllt **werden**.
🇮🇷 فرم باید پر شود.

🇩🇪 Die Aufgabe **musste** gestern **gemacht werden**.
🇮🇷 تمرین باید دیروز انجام می‌شد.

🇩🇪 Das Auto **konnte** repariert **werden**.
🇮🇷 ماشین می‌توانست تعمیر شود.

🇩🇪 Die Briefe **sollten** gestern **geschickt werden**.
🇮🇷 نامه‌ها باید دیروز فرستاده می‌شدند.

## 🏠 Beispiele im Alltag

📋 🇩🇪 Das Formular **muss** unterschrieben **werden**.
🇮🇷 فرم باید امضا شود.

🚭 🇩🇪 Im Krankenhaus **darf** nicht geraucht **werden**.
🇮🇷 در بیمارستان نباید سیگار کشید.

🔧 🇩🇪 Die Maschine **kann** repariert **werden**.
🇮🇷 ماشین می‌تواند تعمیر شود.

📦 🇩🇪 Die Pakete **sollen** heute **geliefert werden**.
🇮🇷 بسته‌ها باید امروز تحویل داده شوند.

## 🔬 Satz-Labor

**Satz:** *Das Formular muss bis Freitag von allen Studenten ausgefüllt werden.*

| Wort / Satzteil | Funktion | Erklärung |
|---|---|---|
| Das Formular | Subjekt | Nominativ |
| muss | Modalverb | Position 2 |
| bis Freitag | Zeitangabe | Frist |
| von allen Studenten | Agens | *von* + Dativ |
| ausgefüllt | Partizip II | *ausfüllen* |
| werden | Hilfsverb | am Ende |

## 📌 Zusätzliche Grammatikübersichten

| Aktiv | Passiv mit Modalverb |
|---|---|
| Man muss das Haus bauen. | Das Haus muss gebaut werden. |
| Man kann das Problem lösen. | Das Problem kann gelöst werden. |
| Man darf hier nicht rauchen. | Hier darf nicht geraucht werden. |
| Man soll die Regel erklären. | Die Regel soll erklärt werden. |

## ⚖️ Nicht verwechseln!

| Paar | Unterschied | Beispiel |
|---|---|---|
| muss gebaut werden / muss bauen | Passiv vs. Aktiv | *Das Haus muss gebaut werden.* / *Ich muss bauen.* |
| kann gemacht werden / kann machen | Passiv vs. Aktiv | *Es kann gemacht werden.* / *Ich kann es machen.* |
| werden / sein | Vorgang vs. Zustand | *muss gebaut werden* / *muss gebaut sein* |

## ❌ Typische Fehler

❌ Das Haus muss gebaut.
✅ Das Haus muss gebaut **werden**.
💡 *werden* am Ende.
🇮🇷 «werden» در انتها.

❌ Das Haus muss werden gebaut.
✅ Das Haus muss **gebaut werden**.
💡 Partizip vor *werden*.
🇮🇷 اسم مفعول قبل از «werden».

❌ Hier darf nicht rauchen werden.
✅ Hier darf nicht **geraucht werden**.
💡 Partizip II.
🇮🇷 اسم مفعول.

❌ Die Aufgabe musste gemacht werden gestern.
✅ Die Aufgabe musste gestern **gemacht werden**.
💡 Zeitangabe vor dem Verbblock.
🇮🇷 قید زمان قبل از بلوک فعلی.

## 🧠 Merksatz wie ein Lehrer

„Modalverb nach vorne, *Partizip + werden* nach hinten – wie ein Paket am Satzende.“

## 🎭 Mini-Dialog

🇩🇪 A: „Muss das Formular heute abgegeben werden?“
🇮🇷 A: «فرم باید امروز تحویل داده شود؟»

🇩🇪 B: „Ja, es **muss** bis 16 Uhr **abgegeben werden**.“
🇮🇷 B: «بله، باید تا ساعت ۱۶ تحویل داده شود.»

🇩🇪 A: „Kann es auch per E-Mail geschickt werden?“
🇮🇷 A: «می‌توان آن را با ایمیل هم فرستاد؟»

🇩🇪 B: „Nein, es **darf** nur persönlich **abgegeben werden**.“
🇮🇷 B: «نه، فقط باید حضوری تحویل داده شود.»

🇩🇪 A: „Und was **soll** ich noch **machen**?“
🇮🇷 A: «و دیگر چه باید بکنم؟»

🇩🇪 B: „Die Kopie **muss** auch **unterschrieben werden**.“
🇮🇷 B: «کپی هم باید امضا شود.»

## 🗣️ Sprechen-Training

1. Sage fünf Regeln mit *muss … werden*.
2. Erkläre, was in deiner Stadt gemacht werden kann.
3. Formuliere drei Verbote mit *darf nicht … werden*.
4. Erzähle, was gestern gemacht werden musste.

## ✍️ Schreib-Training

1. Schreibe fünf Passivsätze mit Modalverben im Präsens.
2. Schreibe drei Sätze im Präteritum.
3. Schreibe einen kurzen Text (6 Sätze) über Regeln in deiner Schule oder Firma.

## ✅ Mini-Test

1. Das Haus muss gebaut ___ . (werden / sein)
2. Das Problem kann gelöst ___ . (werden / worden)
3. Hier darf nicht ___ . (geraucht werden / rauchen werden)
4. Die Aufgabe ___ gestern gemacht werden. (musste / muss)
5. Korrigiere: „Das Haus muss gebaut.“
6. Übersetze: «فرم باید پر شود.»
7. Bilde Passiv: *Man muss das Auto reparieren.*
